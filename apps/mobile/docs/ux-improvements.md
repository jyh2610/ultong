# UX 개선 투두리스트

2026-08-22 UX 리뷰에서 도출된 개선 항목. 우선순위 순으로 정리.

## 우선순위 높음

- [x] 1. **폰트 크기 체계화** — `text-[13px]` 등 arbitrary value가 15개 파일 76곳에서 10.5~26px 사이 19개 값으로 산발적으로 쓰임. tailwind `fontSize` 테마에 의미 단위 토큰을 정의하고 전체 교체. 추가로 가독성을 위해 전체 스케일을 1~2px씩 상향.
- [x] 2. **Detail 화면 공유하기 액션 부재** — 헤더에 공유 버튼 추가, RN 기본 `Share.share()`로 네이티브 공유 시트(카카오톡 포함) 호출. 시설명/카테고리/지역/주소/시간/매칭 상태를 텍스트로 공유.
- [x] 3. **Search 결과 정렬/필터 부재** — "입장가능만 보기" 토글, "매칭도순 정렬" 토글 추가. (거리순은 Facility에 좌표/거리 데이터가 없어 보류 — 위치 데이터 추가 시 별도 항목으로 진행 필요)
- [x] 4. **Home 검색창 최근 검색어/자동완성 없음** — `searchHistoryStore` 추가(세션 내 메모리 저장, 최대 8개). Home에서 검색창이 비어있을 때 최근 검색어 칩 노출(개별삭제/전체삭제), Search 화면 제출 시에도 기록. 자동완성(입력 중 추천)은 제외 — 별도 검색 API/인덱스가 없어 이름/지역 텍스트 매칭만으로는 의미있는 자동완성이 어려움.

## 우선순위 중간

- [x] 5. **Course/Offline 화면 순서 변경(드래그) 불가** — 드래그 대신 위/아래 버튼으로 구현(신규 네이티브 의존성 없이 기존 reanimated만 사용, 사용자 선택). `courseStore`에 `moveSaved` 액션 추가. 부수적으로 Course/Offline 두 화면 모두 표시 순서가 `savedIds` 순서가 아니라 원본 `facilities` 배열 순서를 따르던 버그를 함께 수정(그렇지 않으면 재정렬이 화면에 반영되지 않음).
- [x] 6. **온보딩 진행 표시 없음** — 실제로는 단일 화면 온보딩이라 단계 표시가 성립하지 않아, 사용자 확인 후 "시작하기" 버튼 위에 기대 설정 문구("입력한 조건으로 바로 맞는 장소를 추천해드려요") 추가로 방향 전환.
- [x] 7. **제보하기 후속 피드백 없음** — `reportStore` 추가. Detail 화면에서 제보 시 저장, 같은 시설 재제보 시 버튼 라벨이 "제보 완료 · 검토중"으로 바뀜. MyPage에 "내 제보 내역" 섹션 추가(시설명 + 날짜 + 상태, 제보 없으면 섹션 자체를 숨김).
- [ ] 8. **Offline 저장 시 범위 안내 부족** — 토글 하나로 "기기에 저장"이라고만 되어 있어 무엇이 저장되는지 불명확.

## 우선순위 낮음 (폴리시)

- [ ] 9. **MyPage 정적 항목 무반응** — "알림 설정/데이터 출처 안내/로그아웃"이 눌러도 반응 없는 placeholder.
- [ ] 10. **인기 지역 카드 버그** — `region` 파라미터를 Search로 안 넘겨서 눌러도 필터링 안 됨 (`HomeScreen.tsx` 인기 지역 섹션).
